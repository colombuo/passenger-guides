# Moe Rails passenger guides

Colombuo maintains station and route guides for Moe Rails' website and display partners. The guides describe the usual layout; live service and accessibility notices take precedence during disruption.

Corrections go through a pull request. The guide check validates MDX and uploads the submitted source. When that check passes, the publisher renders an HTML preview of the guide set and links it from its review. The preview is for editorial review, not the live site.
