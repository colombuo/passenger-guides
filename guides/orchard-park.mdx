# Orchard Park

Orchard Park is a single-platform stop. Trains in both directions use the same platform, so check the destination shown on the platform display before boarding.

The station entrance is beside the pedestrian gate on Orchard Avenue. The path from the park is lit until the last scheduled train. The nearest bus stop is on Grove Road, about five minutes away on foot.

Assistance can be requested from the platform help point when staff are not present.
